# مُرشد | المرشد الأكاديمي لجامعة فلسطين الأهلية

يساعد مُرشد طالب الجامعة على الوصول إلى الخطط الدراسية وإجراءات التسجيل واللوائح من سؤال بالعربي. يرفق مصدر الجواب عند توفره، ويحسب الساعات المتبقية بناءً على الإجمالي المنشور والساعات التي أدخلها الطالب.

**الفريق:** رامي مشاعلة وعائشة طالب، جامعة فلسطين الأهلية.
**العرض:** [ملف PowerPoint](docs/Murshid-PAU-Pitch.pptx) يضم قصة الطالب، آلية الاسترجاع، التقييم، ونموذج الاشتراك.
**الموقع:** [مُرشد المنشور](https://murshid-academic-advisor.xramimashala.chatgpt.site/) يرتبط بخادم العرض عند توفره. التشغيل المحلي أدناه يعطيكم نسخة قابلة للفحص على أجهزتكم.

## تشغيل الموقع للحكّام

نزّلوا المستودع عبر **Code → Download ZIP** أو افتحوه في GitHub Desktop، ثم من مجلد المشروع شغّلوا الأمر التالي. يتطلب Python 3.10 فأحدث مع دعم SQLite FTS5، المتوفر في نسخ Python المعتادة.

~~~sh
python run_local.py
~~~

افتحوا [http://127.0.0.1:8000/](http://127.0.0.1:8000/). هالطريقة بتشغّل الواجهة وواجهة REST معًا، والأمثلة المبنية على الفهرس واللوائح تشتغل مباشرة. إذا كان المنفذ مستخدمًا، شغّلوا python run_local.py --port 8001.

| سؤال للتجربة | النتيجة المتوقعة |
| --- | --- |
| كم ساعة لبكالوريوس الذكاء الاصطناعي؟ | 133 ساعة ورابط الخطة |
| أنا طالب إدارة وتأمين مخاطر، قطعت 80 ساعة، كم ضايل؟ | 55 ساعة إذا كانت الـ80 محسوبة في خطة الـ135 ساعة |
| كيف ممكن أنسحب من الجامعة؟ | البوابة الأكاديمية وتسلسل المراجعة مع مرجع الدليل |
| كم سعر الشاي اليوم في المقصف؟ | رد واضح بغياب الدليل |

للإجابات التي تحتاج توليدًا من المقاطع المسترجعة، أضفوا مفتاح Groq كمتغيّر بيئة في نفس نافذة التشغيل ثم أعيدوا تشغيل الخادم.

~~~powershell
$env:GROQ_API_KEY = "ضع مفتاحك هنا"
python run_local.py
~~~

على macOS أو Linux استخدموا export GROQ_API_KEY="ضع مفتاحك هنا". خزنوا المفتاح في البيئة المحلية أو Colab Secrets.

للاختبار الآلي للواجهة والـAPI والمصادر من دون مفتاح:

~~~sh
python run_local.py --check
~~~

ولمعاينة الواجهة الثابتة بأمثلة عرض مضمّنة:

~~~sh
python -m http.server 8080 --directory web
~~~

## تشغيل النموذج في Google Colab

1. ارفعوا [model/Murshid.ipynb](model/Murshid.ipynb) في Colab عبر File → Upload notebook. يحتوي الدفتر على نسخة مضمّنة من النص وفهرس الخطط.
2. من **Secrets** أضيفوا GROQ_API_KEY وفعّلوا **Notebook access**.
3. شغّلوا الخلايا بالترتيب. الخلايا تجهّز الفهرس، تعرض مثالًا، تشغّل الـAPI وتفحصه.
4. العنوان 127.0.0.1 داخل Colab يخص جلسة Colab. للتجربة من المتصفح على جهازكم استخدموا المشغّل المحلي. للتكامل مع واجهة منشورة استخدموا خادم HTTPS يمكن للمتصفح الوصول إليه.

## كيف يعمل النظام؟

1. **المعرفة.** النص منظّم حسب الموضوع والوثيقة والصفحة، مع رابط المصدر الرسمي. فهرس الخطط يجمع الأدلة من جدول الساعات وجداول الفصول المنشورة لبرامج البكالوريوس.
2. **الاسترجاع.** ننظّف صياغة السؤال ونسترجع وحدات نصية باستخدام SQLite FTS5 وBM25. تطابق الأسماء المرن يساعد على مطابقة بعض الاختصارات وتغييرات ترتيب الكلمات.
3. **الحساب والإجابة.** الحسابات وإجراءات البوابة الواضحة تُبنى مباشرة من الأدلة المفهرسة. للأسئلة الأخرى، يصوغ GPT OSS 20B عبر Groq جوابًا من الأدلة المسترجعة. يتحقق الخادم من أن الاقتباس موجود في النص قبل إرجاع المصدر. المشروع يستخدم الاسترجاع المعزّز بالتوليد (RAG).
4. **اختلاف المصادر.** إذا اختلف الإجمالي الصريح مع جمع الفصول الاسترشادية، يعرض النظام الحسبتين مع المراجع. الإجمالي الذي يظهر في خطة الطالب المعتمدة يحدد الحسبة الشخصية.

## عقد الـAPI

- GET /health يفحص الخادم والفهرس.
- POST /ask يستقبل كائن JSON فيه question.
- الطلب الناجح يرجع status وanswer وsources. حالة insufficient_evidence تعني أن الأدلة المتاحة ما كانت كافية.

~~~json
{"question":"كم ساعة لبكالوريوس الذكاء الاصطناعي؟"}
~~~

يتولى المشغّل المحلي الربط تلقائيًا. لاستخدام خادم REST خارجي مع الواجهة الثابتة، اضبط backend.url في [web/app.js](web/app.js) على عنوان /ask المعتمد، واضبط CORS في الخادم حتى يسمح بأصل الموقع. الواجهة تعرض المراجع لما تكون موجودة في استجابة الخادم.
